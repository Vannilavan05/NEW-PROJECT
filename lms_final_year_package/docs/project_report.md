
# Learning Management System (LMS) – Final Year Project

## Abstract
The Learning Management System (LMS) is a web-based platform that enables institutions to manage digital learning activities including course delivery, student enrollment, assignments, attendance, and certification.

## Introduction
Online learning platforms have become essential in modern education. This project develops a web-based LMS using React, Node.js, and MongoDB.

## Problem Statement
Traditional systems lack centralized digital learning platforms.

## Objectives
- Build LMS with course management
- Implement authentication system
- Enable assignment submission
- Generate certificates

## Methodology
Agile development model with iterative development.

## System Architecture
Frontend: React  
Backend: Node.js + Express  
Database: MongoDB

## Implementation
Modules include authentication, course management, video lectures, assignments, attendance, and certification.

## Results
The system allows students to enroll, track progress, and complete courses.

## Conclusion
The LMS provides a scalable digital learning solution.
